## 🚀 Proyectos destacados
 
### 😊 MIJO: Asistente de voz para verificar noticias
 
Aplicación web diseñada principalmente para adultos mayores que permite verificar información o noticias hablando con un asistente, sin tener que escribir.
 
- **Tecnologías:** React, Vite, Node.js, Express, Figma, Web Speech API y API de Anthropic.
- **Funcionalidades:** reconocimiento de voz real, respuestas habladas, respuestas generadas por IA, chat con historial, permite adjuntar imagen o enlace y minijuegos educativos.
- **Mi aporte:** Ideé la aplicación junto a mis compañeros; después diseñé el prototipo en Figma y desarrollé la app funcional.
- **Repositorio:** [Vale-gc/mijo-app](https://github.com/Vale-gc/mijo-app)
- **Demostración:** Puedes probar la app web en [MIJO](https://mijo-frontend.onrender.com)

### 🎡 Festival Perla del Pacífico: Landing page
 
Sitio de una sola página para difundir un festival cultural de música clásica realizado en el Centro Cívico de Guayaquil.
 
- **Tecnologías:** HTML, CSS y JavaScript sobre la plantilla Story de HTML5 UP; Git y GitHub para el control de versiones.
- **Funcionalidades:** diseño adaptable a móvil, con secciones del festival, artistas, director, programa, lugar, galería y contacto.
- **Mi aporte:** Realicé principalmente los cambios en el HTML, escogiendo entre los estilos que ofrecía la plantilla y editando el contenido.
- **Repositorio:** [Vale-gc/perla-pacifico-web](https://github.com/Vale-gc/perla-pacifico-web)
- **Demostración:** https://vale-gc.github.io/perla-pacifico-web/

### 🚨 ResQ-Mesh: red de rescate sin conexión
 
Proyecto de hackathon en equipo. Tras un terremoto, sin internet ni torres celulares, una persona atrapada golpea tres veces y su celular detecta los golpes con el micrófono; el centro de mando recibe la alerta en una lista priorizada. La demo simula la red con dos pestañas del navegador.

- **Tecnologías:** JavaScript (módulos ES), Web Audio API, BroadcastChannel API, HTML5 y CSS.
- **Funcionalidades:** detección de tres golpes por micrófono, SOS manual, alertas por una red mesh simulada, triaje por urgencia y sirena de respuesta.
- **Mi aporte:** Desarrollé el estado global del sistema (`store.js`) y la orquestación que conecta el audio, los canales, los paquetes y la interfaz (`app.js`).
- **Repositorio:** [Geannesan/CS_Hackathon](https://github.com/Geannesan/CS_Hackathon)
- **Demostración:** funciona en local con un servidor simple.
